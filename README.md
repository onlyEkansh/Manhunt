MANHUNT

Real People. Real Movement. Real Gameplay.

Manhunt is a real-world multiplayer location-based web game. It combines physical gameplay with GPS technology to create an interactive experience.

Players join a shared room, select their roles, and use a live map to participate in the game.

🌐 Live Website: https://onlyekansh.github.io/Manhunt/

About the Project

The idea behind Manhunt is to bring a real-life chasing game into a digital experience.

The website helps players:

- Join a game using a room code.
- Choose between Hunter and Player roles.
- Share their locations on a live map.
- Track the game timer and game status.
- Play together in a shared game room.

Main Features

- Room System: Players can join a shared room.
- Role Selection: Choose Hunter or Player.
- Live Location: View player and hunter locations on a map.
- Game Timer: Play within a selected time limit.
- Catch System: A player confirms a catch using their own phone.
- Hide Mode: Hunters can temporarily hide their location.
- Map Controls: Zoom, rotate, follow, and view players.
- Replay: Start another game in the same room.

Technologies Used

How to Play

1. Open the Manhunt website.
2. Allow location access.
3. Join or create a room.
4. Select Hunter or Player.
5. Wait for the host to start the game.
6. Follow the game rules and map.

Safety and Privacy

- Only play with people who have agreed to participate.
- Make sure everyone understands that location is shared during the game.
- Play in a safe, approved area.
- Do not enter roads, restricted areas, or unsafe locations.
- Avoid running or physical contact during gameplay.
